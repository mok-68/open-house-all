# MSU Open House — รวมลิงก์รูปภาพ

เว็บหน้าเดียวสำหรับรวมลิงก์รูปภาพกิจกรรม **Open House คณะวิทยาการสารสนเทศ มหาวิทยาลัยมหาสารคาม**
เปิด `index.html` แล้วเจอลิงก์รูปทั้งหมดทันที ไม่ต้องติดตั้งหรือ build อะไร

## ไฟล์ในโปรเจกต์

```text
openhouse/
├─ index.html        ← หน้าเว็บทั้งหมด (แก้ลิงก์และข้อความที่นี่)
├─ background1.jpg   ← ภาพพื้นหลัง / ภาพปกการ์ด
├─ background.jpg
├─ icon.jpg
├─ icon1.png         ← ตราคณะ (ไอคอนเว็บ)
└─ README.md
```

## เพิ่ม / แก้ไขลิงก์รูป

1. เปิด `index.html` ด้วย Notepad หรือ VS Code
2. หาคอมเมนต์ `เพิ่มลิงก์ใหม่` ในส่วน `<section class="link-grid">`
3. คัดลอกการ์ดทั้งก้อน ตั้งแต่ `<a class="link-card"` ถึง `</a>`
4. วางต่อจากก้อนสุดท้าย แล้วแก้
   - `href="..."` → ลิงก์ Google Drive (หรือเว็บที่เก็บรูป)
   - `<span class="card-album">` → ชื่อหมวด
   - `<h3>` → ชื่ออัลบั้ม
   - `<p>` → คำอธิบายสั้น ๆ
   - `<img src="...">` → ชื่อไฟล์รูปปก (วางไฟล์ไว้โฟลเดอร์เดียวกับ `index.html`)
5. บันทึกแล้วรีเฟรชหน้าเว็บ ตัวนับจำนวนลิงก์จะอัปเดตเอง

## เปลี่ยนรูปตกแต่ง

- **พื้นหลังทั้งหน้า:** แก้ `--photo: url("background1.jpg");` ในบล็อก `<style>` ด้านบน
- **แบนเนอร์หัวเว็บ:** แก้ `src` ของ `<img class="banner-img" ...>`
- **รูปปกการ์ดแต่ละใบ:** แก้ `src` ของ `<img>` ในการ์ดนั้น

## ข้อควรรู้

- ต้องแชร์ไฟล์/โฟลเดอร์ใน Google Drive เป็น **“ทุกคนที่มีลิงก์สามารถดูได้”** มิฉะนั้นคนอื่นจะเปิดไม่ได้
- หน้าเว็บใช้ฟอนต์จาก Google Fonts ถ้าออฟไลน์จะแสดงฟอนต์ระบบแทน
- ไม่มีข้อมูลถูกส่งไปที่ไหน เว็บเป็นไฟล์ static ล้วน
