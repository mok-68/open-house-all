# รวมลิงก์รูปภาพ — Open House วิทยาการสารสนเทศ มมส

เว็บหน้าเดียวสำหรับรวมลิงก์อัลบั้มรูปภาพงาน Open House คณะวิทยาการสารสนเทศ มหาวิทยาลัยมหาสารคาม

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | ทั้งหน้าเว็บ (HTML + CSS + JS ฝังในไฟล์เดียว) |
| `background1.jpg` | รูปหัวเว็บ / พื้นหลัง / ปกการ์ด (ถ้าไม่มีจะใช้พื้นหลังไล่สีแทน) |
| `README.md` | ไฟล์นี้ |

## วิธีแก้ไข

เปิด `index.html` ด้วย Notepad หรือ VS Code

### 1. เปลี่ยนลิงก์อัลบั้ม

หา `<a class="link-card" href="...">` ในการ์ดที่ต้องการ แล้วใส่ลิงก์ Google Drive ของคุณ

> สำคัญ: ตั้งค่าแชร์ของโฟลเดอร์ Drive เป็น **“ทุกคนที่มีลิงก์”** ไม่งั้นคนอื่นจะเปิดไม่ได้

### 2. เพิ่มอัลบั้มใหม่

คัดลอกบล็อกนี้ไปวางใน `<ul class="link-grid" id="linkGrid">` แล้วแก้ข้อความ/ลิงก์

```html
<li>
  <a class="link-card" href="ลิงก์อัลบั้ม" target="_blank" rel="noopener">
    <div class="cover"></div>
    <div class="body">
      <h3>ชื่ออัลบั้ม</h3>
      <p class="meta">คำอธิบายสั้น ๆ</p>
      <span class="go">เปิดอัลบั้ม <span>→</span></span>
    </div>
  </a>
</li>
```

### 3. เปลี่ยนรูปพื้นหลัง

วางไฟล์ชื่อ `background1.jpg` ไว้ข้าง ๆ `index.html` (จะถูกใช้เป็นหัวเว็บ พื้นหลัง และปกการ์ดอัตโนมัติ)

ถ้าอยากใช้ชื่อไฟล์อื่น ให้แก้บรรทัดนี้ในส่วน `:root` ด้านบนของ `<style>`

```css
--photo: url("background1.jpg");
```

### 4. เปลี่ยนสี

แก้ตัวแปรใน `:root` เช่น `--bg` (พื้นหลัง), `--card` (การ์ด), `--accent` / `--accent-2` (สีเน้น)

## เปิดดูในเครื่อง

ดับเบิลคลิก `index.html` ได้เลย หรือรันเซิร์ฟเวอร์ local

```bash
python -m http.server 8123 --bind 127.0.0.1
```

แล้วเปิด http://127.0.0.1:8123/
