เพิ่มลิงก์: เปิดไฟล์ index.html ด้วย Notepad หรือ VS Code แล้วคัดลอกบล็อก <a class="link-card" ...> ... </a> ไปวางต่อจากของเดิม จากนั้นแก้ href="..." เป็นลิงก์ Google Drive (หรือเว็บอื่น) ที่ต้องการ

เปลี่ยนรูปปก: เอาไฟล์รูปมาวางไว้โฟลเดอร์เดียวกับ index.html แล้วแก้ src="background1.jpg" ในการ์ดนั้นเป็นชื่อไฟล์ใหม่

เปลี่ยนภาพพื้นหลังทั้งหน้า: แก้บรรทัด --photo: url("background1.jpg"); ในส่วน <style> ด้านบนของไฟล์

สำคัญ: ต้องตั้งค่าแชร์ใน Google Drive เป็น “ทุกคนที่มีลิงก์สามารถดูได้” คนอื่นจึงจะเปิดดูรูปได้
